## 📌 Proje Hakkında

Sinematik video girişli animasyonlu düğün davetiyesi. Geri sayım, takvime ekleme, anı galerisi ve LCV formu içeriyor. Python ve SQLite ile çalışan yönetici panelinden katılımcı istatistikleri, Excel çıktısı ve müşteri hesapları yönetiliyor. Saray, klasik araba ve yat olmak üzere üç tema.
